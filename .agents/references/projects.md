# Projects and portfolio

This reference combines Ahmed's archived home-page descriptions, the original project icons embedded in that archive, repository READMEs, and App Store listings checked on 2026-09-27. The twelve icons below are local copies, so the reference does not depend on the old image host. App Store listings describe the products, not Ahmed's individual contributions. The linked Google Sites project pages were not included in the supplied archive and could not be retrieved during this check.

## Open source work shown on the portfolio

- **Imperative Navigation:** Swift package for programmatic, coordinator-based navigation in SwiftUI. Its README describes push, sheet, and full-screen presentations and testable coordinators. [Repository and source](https://github.com/ahmdmhasn/swiftui-imperative-navigation). App Store: not applicable. Icon: no dedicated project icon was supplied in the archived portfolio.
- **Xcode Cloud Dispatch:** GitHub Action for triggering Xcode Cloud builds for Flutter and native iOS projects, detecting app versions, and linking to build summaries. [Repository and source](https://github.com/ahmdmhasn/xcode-cloud-dispatch-action). App Store: not applicable. Icon: no dedicated project icon was supplied in the archived portfolio.
- **Dokan Store:** free educational iOS commerce project for the Motoon Mentorship Program team, with a layered Swift codebase and multiple contributors. [Repository and source](https://github.com/motoon-eg/dokan-store). App Store: no listing identified in the repository or supplied portfolio. Icon: no dedicated project icon was supplied in the archived portfolio.
- These are selected portfolio entries. Their descriptions do not establish sole authorship or current maintenance.

## Previous website portfolio

The archived Google Sites home page used the heading “⚜️ Wall of Glory ⚜️” for these entries. Treat its descriptions, company credits, and marketing language as historical source claims. Exact contributions and current availability require confirmation. “No verified listing” means a matching App Store listing could not be established; do not substitute similarly named apps.

- **Swvl:** The archive described comfortable, affordable, reliable, and safe rides in Egypt, Pakistan, Kenya, Jordan, Argentina, and Brazil, and credited Swvl Holdings Corp., which it called Nasdaq-listed. [Swvl – Daily Rides on the App Store](https://apps.apple.com/eg/app/swvl-daily-rides/id1214486024) uses the exact ID linked in the archive; Apple's listing describes booking bus rides and names Swvl Inc. as seller. [Archived icon](icons/swvl.png) (1024 × 1024 PNG). Ahmed's iOS Customer App work is in [experience](experience.md).
- **Festival Community:** Helped Cairo Festival City unit owners and tenants request services, send complaints, and invite guests. Credited to VictoryLink. [Historical project page](https://sites.google.com/view/ahmdmhasn/projects/festival-community?authuser=0). App Store: no verified listing. [Archived icon](icons/festival-community.png) (512 × 512 PNG).
- **CashCall:** Payment-services app described as simple and fast. Credited to VictoryLink. [Historical project page](https://sites.google.com/view/ahmdmhasn/projects/cashcall?authuser=0). App Store: no verified listing. [Archived icon](icons/cashcall.png) (900 × 900 PNG).
- **UpTownGym:** Fitness-services app focused on variety, quality, and a friendly atmosphere. [Historical project page](https://sites.google.com/view/ahmdmhasn/projects/UpTownGym?authuser=0). App Store: no verified listing. [Archived icon](icons/uptowngym.png) (900 × 900 PNG).
- **HallaTravel:** Travel deals from selected Egyptian tour operators. The archive's “#1 Application” ranking is an unverified marketing claim. [Halla: Hotels & Packages on the App Store](https://apps.apple.com/eg/app/halla-hotels-packages/id1450827839) describes booking Egyptian hotels, trips, honeymoon packages, and activities; the developer is Halla For Tourism Marketing. The same App Store ID now uses the shorter Halla name; the name and travel focus support this match, though the archive did not give its App Store ID. [Historical project page](https://sites.google.com/view/ahmdmhasn/projects/hallatravel?authuser=0). [Archived icon](icons/hallatravel.png) (900 × 900 PNG).
- **Iraq Electricity:** View and pay electricity bills and monitor consumption. Credited to Unicom Group. [Historical project page](https://sites.google.com/view/ahmdmhasn/projects/iraq-electricity?authuser=0). App Store: no verified listing. [Archived icon](icons/iraq-electricity.png) (900 × 900 PNG).
- **Aaber / عابر:** Same-day shipment delivery to a chosen city. [Aaber – عابر on the App Store](https://apps.apple.com/us/app/aaber-%D8%B9%D8%A7%D8%A8%D8%B1/id1511307079) repeats the archived English description and adds pickup and delivery location selection. Apple lists Almusand Co. as developer; the archive did not name one. [Historical project page](https://sites.google.com/view/ahmdmhasn/projects/aaber?authuser=0). [Archived icon](icons/aaber.png) (900 × 900 PNG).
- **WhatsStore:** Find and chat with nearby sellers to ask for products. [Historical project page](https://sites.google.com/view/ahmdmhasn/projects/whatsstore?authuser=0). App Store: no verified listing; current similarly named products are not established as this app. [Archived icon](icons/whatsstore.png) (900 × 900 PNG).
- **Multinet:** The archive supplied only the name, image, and “See More” link; no product description. [Historical project page](https://sites.google.com/view/ahmdmhasn/projects/multinet?authuser=0). App Store: no verified listing; multiple unrelated Multinet apps exist. - **iRead App:** Books platform in the Middle East, credited to VictoryLink. The archive's “biggest and most popular” statement is an unverified marketing claim. [Historical project page](https://sites.google.com/view/ahmdmhasn/projects/etadweer?authuser=0). [Archived icon](icons/etadweer.png) (900 × 900 PNG).

Ahmed's LinkedIn export says this ITI graduation project was selected among Egypt's top 10 projects. [Historical project page](https://sites.google.com/view/ahmdmhasn/projects/et3am?authuser=0). App Store: no verified listing. [Archived icon](icons/et3am.png) (1280 × 1280 PNG).
